# Coachable Robots

An edge-to-cloud pipeline for training robot manipulation policies using imitation learning. Students and makers **coach** a SO-ARM101 robotic arm by demonstrating tasks with an Xbox controller — no programming required.

Demonstrations are recorded as LeRobot datasets, uploaded to HuggingFace Hub, trained on Chameleon Cloud MI100 GPUs, and the resulting policy is pulled back to the robot for autonomous execution.

## How it works

```
┌───────────────────────────┐                          ┌────────────────────────────┐
│    Raspberry Pi 5 (Edge)  │                          │  Chameleon MI100 (Cloud)   │
│                           │                          │                            │
│  Xbox controller teleop   │   HuggingFace Hub       │  LeRobot training          │
│  + SO-ARM101 follower     │  ────── dataset ──────> │  ACT / Diffusion / Pi0     │
│  + 2x USB cameras         │                          │                            │
│  + LeRobot recorder       │  <── checkpoint pull ── │  ROCm 6.3 + PyTorch 2.7    │
│                           │                          │  (gfx908 bare metal)       │
│  Docker container         │                          │  Ansible-provisioned       │
└───────────────────────────┘                          └────────────────────────────┘
        │                                                        │
        └──────────── Chameleon Jupyter (orchestration) ─────────┘
                        python-chi 1.0+ · CoachableRobots_v3.ipynb
```

## Data flow

1. **Coach** — Pi runs `lerobot-record` with Xbox controller; episodes saved locally
2. **Push** — Dataset uploaded to HuggingFace Hub (`--dataset.push_to_hub=true`)
3. **Train** — MI100 node pulls dataset by `repo_id`, trains policy, saves checkpoints
4. **Upload** — `hf upload` pushes checkpoint to HF Hub
5. **Fetch** — Pi downloads trained policy (`hf download`)
6. **Deploy** — Pi runs `lerobot-record --policy.path=...` for autonomous execution

## Quick start

### 0. Enroll Pi 5 on CHI@Edge

Follow [docs/pi5-chi-edge-setup.md](docs/pi5-chi-edge-setup.md) to register your
Raspberry Pi 5 as a CHI@Edge device using BalenaOS.

### 1. Collect demonstrations (Pi edge)

```bash
docker run -it --privileged -v /dev:/dev -e HF_TOKEN=hf_xxx coachable-robots-pi

# Inside container:
bash scripts/collect_demos.sh my_dataset 50
```

### 2. Provision the training node (Chameleon Jupyter)

Open `CoachableRobots_v3.ipynb` and run through the provisioning cells. This will:
- Lease a MI100 bare-metal node via python-chi
- Run the Ansible playbook to install ROCm + LeRobot
- Launch training against your HuggingFace dataset

```bash
# Or run Ansible directly:
cd ansible
ansible-playbook -i inventory.ini playbooks/setup_training_node.yml
```

### 3. Train on the MI100

```bash
ssh cc@<floating_ip>
conda activate lerobot
python lerobot/scripts/train.py \
    --dataset.repo_id=USER/dataset_name \
    --policy.path=lerobot/act \
    --policy.device=cuda \
    --output_dir=outputs/train/act_run1
```

### 4. Deploy the policy (Pi edge)

```bash
bash scripts/fetch_checkpoint.sh USER/my_model

lerobot-record \
    --policy.path=/app/checkpoints/latest \
    --dataset.single_task="Pick up the block"
```

## Platform support

Recording works on Pi 5 (CHI@Edge and local), Linux laptops, and macOS.
Both SO-ARM100 and SO-ARM101 are supported (SO-ARM101 is a cosmetic update).
See [docs/platform-support.md](docs/platform-support.md) for the full
compatibility matrix of teleop inputs, simulation, and per-platform install.

## Hardware requirements

| Component | Spec |
|-----------|------|
| Robot | SO-ARM101, 6-DOF, Feetech STS3215 servos |
| Edge compute | Raspberry Pi 5 |
| Controller | Xbox controller (via `xbox_soarm_teleop`) |
| Cameras | 2x USB cameras |
| Cloud GPU | AMD Instinct MI100 (gfx908, 32 GB HBM2) |

## MI100 notes (gfx908)

- No Flash Attention 2 (requires gfx90a+) — use **ACT** as the default policy
- No hipBLASLt
- Pi0 3B works with: `--policy.gradient_checkpointing=true --policy.dtype=bfloat16 --batch_size=8`
- Use `rocm-smi`, not `nvidia-smi`
